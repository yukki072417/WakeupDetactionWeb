# ディレクトリ・コーディング規約

## コーディング規約

定められているコーディング規約に沿って、ファイル保存時に自動的にフォーマットされるのであまり気にしなくていいです。

## **ディレクトリ構成規約**

ディレクトリ構成はこのようになっている

```
./
├─ docs/
│ ├─ README.md
│ └─ instruction.md <-いまここ
└─ src/
  ├─ assets
  ├─ commons ①/
  │ ├─ components ①-1
  │ ├─ hooks ①-2
  │ ├─ contexts ①-3
  │ └─ utils ①-4
  └─ features/
    └─ <機能名>②/
      ├─ components ②-1
      ├─ hooks ②-2
      ├─ contexts ②-3
      ├─ 機能名.tsx
      └─ 機能名.css
```

| 番号 | ディレクトリ・ファイル名    | 意味                                                   |
| ---- | --------------------------- | ------------------------------------------------------ |
| ①    | commons                     | プロジェクト全体で使用される処理を格納するディレクトリ |
| ①-1  | commons/components          | プロジェクト全体で使用されるReactコンポーネント        |
| ①-2  | commons/hooks               | プロジェクト全体で使用されるカスタムhooks              |
| ①-3  | commons/contexts            | プロジェクト全体で使用されるカスタムcontexts           |
| ①-3  | commons/utils               | プロジェクト全体で使用されるビジネスロジック           |
| ②    | feature/<機能名>            | その機能でのみ使用される処理を格納する                 |
| ②-1  | feature/<機能名>/components | その機能でのみ使用されるReactコンポーネント            |
| ①-2  | feature/<機能名>/hooks      | その機能でのみで使用されるカスタムhooks                |
| ①-3  | feature/<機能名>/contexts   | その機能でのみで使用されるカスタムcontexts             |
| ①-3  | feature/<機能名>/utils      | その機能でのみで使用されるビジネスロジック             |
